# ADR-0002: Локальные веса моделей не входят в Git

Статус: принято для реализации этапа 2.

## Контекст

Модели Llama-3.2-3B и Qwen3-4B-Base уже скачаны на экспериментальной машине в
локальные каталоги `models/llama-3.2-3b` и `models/qwen3-4b-base`.

## Решение

- Не копировать и не архивировать веса вместе с исходным кодом бенчмарка.
- Сохранить `models/` в корне рабочего репозитория и исключить содержимое из Git.
- В model config одновременно хранить:
  - логический Hugging Face `id`;
  - зафиксированный `revision`;
  - относительный `local_path`;
  - `dtype`.
- Будущий `LMAdapter` должен поддерживать загрузку из `local_path` без обращения к
  сети, а run artifacts должны сохранять model id и revision как provenance.

## Последствие

Существующий локальный model-probe репозиторий можно расширять кодом бенчмарка
без повторной загрузки моделей и без попадания многогигабайтных весов в Git.
