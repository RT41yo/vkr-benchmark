# ADR-0015: Проверка готовности этапа 2 и версия v0.2

- **Статус:** принято
- **Дата:** 2026-09-05

## Контекст

На этапе 2 была создана базовая инфраструктура бенчмарка для методов Bins, Huffman и Arithmetic Coding: общий запуск экспериментов, расчет основных метрик, проверка кодирования и декодирования, а также сохранение результатов.

После завершения реализации нужно было определить, когда этап действительно можно считать готовым. Одного успешного запуска или ручной проверки файлов для этого недостаточно.

## Решение

Для этапа 2 вводится автоматическая проверка готовности с помощью скрипта:

`scripts/check_stage2_readiness.py`

Проверка должна подтверждать, что:

- основные компоненты этапа 2 присутствуют;
- результаты Bins, Huffman и Arithmetic Coding успешно сформированы;
- идентификаторы запусков корректны и не дублируются;
- секрет восстанавливается без ошибок в проверочных запусках;
- основные метрики рассчитаны;
- результаты сохранены в ожидаемом формате;
- тесты проекта проходят успешно.

Бесконечное значение `D_KL(P_reference || Q_stego)` само по себе не считается ошибкой, поскольку для некоторых методов оно является ожидаемым результатом из-за различия поддержек распределений.

Версия `v0.2` означает техническую готовность базовой инфраструктуры после этапа 2. Это еще не окончательная версия экспериментального протокола бенчмарка.

## Последствия

После успешного прохождения проверки этап 2 можно считать технически завершенным и переходить к этапу 3 — проверке воспроизводимости базовых методов.

Эту же проверку можно повторно запускать после последующих изменений проекта, чтобы убедиться, что базовая инфраструктура не была случайно нарушена.
