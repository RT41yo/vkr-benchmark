# Stage 7 — Final Evaluation Audit & Analysis

## Назначение и неподвижные входы

Этот checkpoint выполняет только post-test аудит сохранённых score и описательный анализ. Никакого повторного inference, переобучения, выбора порога, смены seed, инверсии score, изменения состава test или перезаписи исходных артефактов. Основной RoBERTa E4 seed 713 (epoch 4) для каждой LM; TF-IDF — baseline. E8 не участвует в test.

## Воспроизведение

Из корня репозитория, после отдельного коммита исходного отчёта, выполнить:

```bash
source .venv/bin/activate
pytest -q
PYTHONPATH=src python scripts/audit_stage7_final_evaluation.py
PYTHONPATH=src python scripts/audit_stage7_final_evaluation.py --write-report
```

Первый запуск скрипта не пишет файлов. Если отсутствует сам файл lock, read-only аудит score возможен (`lock_file_verified=false`), но запись результатов запрещена. На рабочем репозитории ожидается `lock_file_verified=true` в обоих запусках. Ошибка SHA или метрик должна останавливать анализ. Не менять ожидаемые хеши или исходные файлы для обхода ошибки.

`--write-report` создаёт четыре производных артефакта в `results/stage7/analysis/`:

- `final_evaluation_audit.json`: контрольные суммы, объём проверки, численные расхождения и Spearman correlations;
- `stage6_stage7_operating_points.csv`: все 30 строк Stage 6 с добавленными результатами двух детекторов и диагностикой длины;
- `roc_auc_llama-3.2-3b.svg` и `roc_auc_qwen3-4b-base.svg`: графики всех 15 точек для каждой LM, оба детектора, индивидуальные 95% CI и линия AUC=0.5.

Скрипт не перезаписывает отличающийся ранее созданный производный файл; побайтово совпадающие выходы допускаются. SVG не требуют matplotlib. Используются установленные NumPy, scipy (зависимость scikit-learn) и scikit-learn. Никакой GPU не нужен.

## Независимый пересчёт

Проверяются 7200 строк score, уникальность ключа (detector, record_id), совпадение metadata между двумя детекторами, принадлежность к test, классы, допустимость score, 1800 пар, 3600 record_id, 24 статьи, баланс и кратность повторов 3/2 на каждую рабочую точку каждой LM. Проверяются точные 60 point rows и 4 pooled rows. Для каждого набора заново вычисляются ROC-AUC, AP, trapezoidal PR-AUC, accuracy, balanced accuracy, precision, recall, F1, confusion matrix, support и CI. Порог — закреплённый validation threshold, без подбора. Численный допуск 1e-10.

Для bootstrap используются отсортированные группы одинаковых score и взвешенная статистика Манна–Уитни (половинный вклад ties), а не исходная матрица попарных сравнений. Для каждого ресэмпла веса всех текстов одной статьи одинаковы; используется тот же seed 731, 2000 общих выборок по 24 статьям, percentile 95% CI. Синтетический тест сопоставляет результат с буквальным повторением целых групп и sklearn ROC-AUC.

Проверка на присланных реальных score и отчёте: **64/64 страт, 64/64 интервалов, 1024 поля, максимальное абсолютное численное расхождение 0.0**. Диагностика длины перенесена из исходного отчёта, не пересчитана по score (в raw predictions нет текстов). Это аудит численных метрик, а не независимое воспроизведение inference или проверки весов. Файл lock отсутствует в ранее присланном pre-lock source-only snapshot, поэтому его собственные байты проверяются у автора локально.

## Научная интерпретация

| LM | TF-IDF pooled ROC-AUC [95% CI] | RoBERTa pooled ROC-AUC [95% CI] |
|---|---|---|
| Llama | 0.6984 [0.6773; 0.7217] | 0.8014 [0.7881; 0.8157] |
| Qwen | 0.7094 [0.6851; 0.7344] | 0.7830 [0.7668; 0.8005] |

RoBERTa даёт больший pooled AUC в обеих LM. Pooled AUC — результат сравнения score по всем точкам, а не среднее по 15 AUC. Разность AUC приведена описательно; отдельный CI разности не рассчитан. Bins обнаруживается почти идеально; Huffman и DAIRstega часто демонстрируют высокую обнаруживаемость. Для AC наблюдается сильная зависимость от выбранной рабочей точки; ADG, Discop, RRC и AC k50000 имеют многие AUC в окрестности 0.5. Это описание конкретных настроек и pooled text-only детекторов, не доказательство безопасности методов. Для Discop/Llama AUC=0.3972, CI [0.3061; 0.4959]: обратное ранжирование, не результат «лучше случайного» с точки зрения защищённости. Инверсия после test не используется. Интервалы индивидуальные, не скорректированы на множественные сравнения.

### Stage 6 ↔ Stage 7

Соединение по (model, method_id, method_point_id), не только по point_id (у ADG и Discop одинаковый `default`). Для каждого детектора и каждой LM вычисляется Spearman rho по 15 operating points. Основной описательный результат для RoBERTa:

| Stage 6, медианы | Llama | Qwen |
|---|---:|---:|
| KL(P_stego ∥ P_ref), bits | 0.8786 | 0.8714 |
| TVD | 0.8929 | 0.8571 |
| PPL raw LM | -0.0143 | 0.5286 |
| Bits per token | -0.2393 | 0.1036 |

Второе направление KL(P_ref ∥ P_stego) сохраняется согласно ADR-0012: отдельно `kl_ref_to_stego_infinite_rate_ok` по 15 точкам (для RoBERTa rho=0.6172/0.5401) и `kl_ref_to_stego_finite_median_bits` по конечному подмножеству из трёх точек на LM. Последнее — только описательный расчёт на n=3; вывод о генеральной совокупности не делается. Пропущенные конечные медианы не заменяются нулём или произвольным числом. В объединённом CSV сохранены исходные значения обоих направлений, доля бесконечных и количество успешных/неуспешных запусков.

Корреляции exploratory, без p-value или причинных выводов: точки внутри семейства зависимы, агрегаты Stage 6 могут относиться к подмножеству успешных запусков, тогда как оценка Stage 7 охватывает все сформированные test-тексты, включая 97 hard failures. PPL — raw-LM PPL выбранных stego-токенов. Это эмпирическое согласование распределительных метрик и обнаруживаемости в исследованных условиях, а не универсальная гарантия.

### Ограничение длины

В основном отчёте зафиксированы 33/3600 текстов с длиной выше 512 RoBERTa tokens. RRC/Qwen: 12/48 cover (25%) и 14/48 stego (29.17%). Это существенное ограничение именно для этой страты. TF-IDF получает полный текст; его результат также близок к 0.5, но это не исключает эффект усечения. Отдельная диагностика RRC с cover фиксированной длины 256 и quality controls, включая length-only classifier и shuffled labels, остаются отдельными экспериментами по протоколу. Не менять основной test scoring.
