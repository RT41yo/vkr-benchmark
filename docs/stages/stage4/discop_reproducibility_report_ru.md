# Этап 4 — отчет о воспроизводимости Discop

**Дата фиксации:** 2026-10-02  
**Метод:** Discop  
**Авторская реализация:** `comydream/Discop@3c3a10099a242eae405b49cc4d09fba1abb148ad`  
**Модель в бенчмарке:** `meta-llama/Llama-3.2-3B@13afe5124825b4f3751f836b40dafda64c1ed062`

## Цель проверки

Целью проверки было убедиться, что реализация Discop в бенчмарке сохраняет характерные свойства метода: высокую эффективность использования энтропии, отсутствие распределительного искажения относительно опорного распределения и точное восстановление скрытого сообщения после передачи стеготекста через обычный текстовый канал.

Численное совпадение с результатами статьи не ставилось целью этого запуска, поскольку в публикации использовались GPT-2 и контексты IMDb, а в бенчмарке применяется Llama-3.2-3B.

## Ориентир из публикации

Для Discop в публикации сообщается эффективность использования энтропии примерно на уровне **92–95%** при нескольких значениях `top-p`. Для распределительного искажения приводится нулевой KLD. Эти результаты используются как ориентир для проверки характерного поведения метода, а не как целевые числа для прямого сравнения с Llama-3.2-3B.

## Интерпретация

Полученные результаты подтверждают характерное для Discop сочетание высокой пропускной способности и малого распределительного искажения. В четырех из пяти точек было использовано более 90% доступной энтропии, а максимальное наблюдаемое значение составило **99.45%** при `top-p = 0.98`.

Нулевые значения KL и TVD соответствуют теоретическому свойству Discop, согласно которому распределение стеганографического выбора совпадает с опорным распределением. В бенчмарке это свойство задается аналитически и не выводится из одного короткого экспериментального запуска.

Значение при `top-p = 1.00` заметно ниже остальных точек, однако этот результат нельзя интерпретировать как доказательство ухудшения метода без ограничения `top-p`. Каждое значение приводит к собственной последовательности токенов и собственным распределениям языковой модели, поэтому для вывода о влиянии `top-p` требуется серия повторных запусков. Такая проверка относится к последующим этапам исследования.

## Вывод

На Llama-3.2-3B реализация Discop успешно воспроизводит ожидаемое качественное поведение метода: скрытое сообщение восстанавливается точно, текстовый канал не нарушает последовательность токенов, распределительное искажение отсутствует, а эффективность использования энтропии в данном запуске составила от **78.47% до 99.45%**.

Результат следует считать **воспроизведением характерного поведения**, а не прямым численным воспроизведением таблицы из публикации. Проверка на резервной модели Qwen3-4B-Base и окончательная фиксация соответствия авторской реализации оформляются отдельно перед закрытием Discop в рамках Этапа 4.
