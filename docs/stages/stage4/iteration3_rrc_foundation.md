# Этап 4: первая итерация RRC

В этой итерации добавлена нормализованная реализация RRC на основе актуального авторского ядра `dae326259...`.

Подключены фиксированная длина полезной нагрузки, масштабируемая точность `Decimal`, синхронизированные вращения по общему ключу, проверенное завершение и финальное восстановление сообщения. Общие ограничения распределения остаются частью `P_reference`; собственного `top-k` у нормализованного адаптера нет.

Для распределительных метрик строится явное `Q_stego` по длинам токенных интервалов. Этот расчет выполняется отдельно от выбора токена и не входит в показатели скорости метода.

Следующий шаг после локальных тестов — реальный запуск на Llama-3.2-3B, после чего выполняется прямое сравнение с зафиксированной авторской реализацией и характерным результатом публикации.
