# Этап 4 — отчет о воспроизводимости ADG

**Дата фиксации:** 2026-10-10  
**Метод:** Adaptive Dynamic Grouping (ADG)  
**Публикация:** Siyu Zhang, Zhongliang Yang, Jinshuai Yang, Yongfeng Huang, *Provably Secure Generative Linguistic Steganography*, Findings of ACL-IJCNLP 2021  
**Авторская реализация:** `Mhzzzzz/ADG-steganography@b4a7e802a97bc3a3b84d07e63f24627b16c51a10`  
**Модель в бенчмарке:** `meta-llama/Llama-3.2-3B@13afe5124825b4f3751f836b40dafda64c1ed062`

## Цель проверки

Проверка должна была подтвердить три вещи: нормализованная реализация следует Algorithm 1 публикации, полный цикл `secret → stegotext → recovered secret` работает в общей инфраструктуре, а характерное научное поведение ADG — высокая полезная нагрузка при малом, но ненулевом искажении распределения — наблюдается на выбранной современной языковой модели.

Для ADG дополнительно возникла важная задача воспроизводимости: публичный авторский код содержит локальное расхождение с Algorithm 1 в функции `near()`. Поэтому соответствие публикации и соответствие публичному репозиторию проверялись раздельно.

## Какой результат публикации воспроизводится

В Table 1 статьи для ADG сообщаются следующие значения embedding rate (ER) и KLD1:

| Корпус | ER, бит/токен | KLD1, бит/токен |
|---|---:|---:|
| Movie | 5.147 | 0.033 |
| News | 5.650 | 0.027 |
| Tweet | 5.411 | 0.048 |

В статье KLD1 соответствует распределительному отклонению между исходным распределением языковой модели и распределением после ADG. Для нашего normalized benchmark ближайший прямой аналог — `D_KL(P_reference || Q_stego)`.

Прямое численное совпадение с Table 1 не является целью: авторы использовали отдельные word-level LSTM, другие корпуса и словарную токенизацию, тогда как benchmark использует Llama-3.2-3B, subword-токены и собственный канонический `P_reference`.

Проверяемый характерный результат формулируется так:

> ADG должен обеспечивать существенную embedding rate, одновременно сохраняя малое, но в общем случае ненулевое распределительное искажение.

Это принципиально отличает ADG от Discop и RRC: для ADG из-за дискретности групп обычно ожидается `Q_stego != P_reference`, тогда как для методов сохранения распределения различие должно оставаться на уровне численной точности.

## Нормализованная семантика

ADG получает уже подготовленный `P_reference`; общие `temperature`, `top-k`, `top-p` и фильтрация special tokens выполняются до метода.

На каждом рекурсивном уровне число групп выбирается по максимальной вероятности, после чего токены распределяются по `2^b` группам с целевой близкой суммарной массой. Секретные биты в little-endian порядке выбирают индекс группы. Рекурсия продолжается внутри выбранной группы, пока максимальная вероятность в текущем нормализованном распределении не превышает `0.5`. Затем токен выбирается стохастически внутри терминальной группы.

Публичный репозиторий не содержит готового decoder. Для benchmark реализован обратный decoder, который по наблюдаемому token ID и тому же `P_reference` воспроизводит путь группировки и восстанавливает индексы выбранных групп.

## Real-LM smoke

Первый end-to-end запуск на Llama-3.2-3B использовал 16 carrier tokens, `secret_id = 000001`, `method.random_seed = 42`, общий `top-k = None` и `top-p = 1.0`.

Результат:

| Показатель | Значение |
|---|---:|
| Carrier tokens | 16 |
| Payload | 71 бит |
| BPT | 4.4375 |
| Mean `D_KL(P_ref || Q)` | 0.009492 бит/токен |
| Mean `D_KL(Q || P_ref)` | 0.009787 бит/токен |
| Mean TVD | 0.026408 |
| BER | 0 |
| Token-sequence round-trip | точный |
| Secret round-trip | точный |
| Decoder complete | да |

`Q_stego` строился независимо полным обходом дерева групп (`q_mode = exact_enumeration`, `q_source = independent_enumeration`). Таким образом, ненулевой KL не подставлялся из теории и не вычислялся по фактически выбранной ветви.

В этом коротком запуске отношение `payload_bits / sum H(P_reference)` составило 105.035%. Это не трактуется как превышение информационно-теоретического предела: знаменатель использует энтропию исходного `P_reference`, тогда как ADG фактически сэмплирует из отличающегося `Q_stego`, а само отношение рассчитано по одной короткой реализованной траектории.

## Paper-vs-repository conformance

Независимая paper-faithful реализация Algorithm 1 была сравнена с normalized ADG на 132 синтетических распределениях.

Результат:

- normalized ADG vs Algorithm 1: 0 failures;
- max `|Q_normalized - Q_paper| = 5.551e-17`;
- literal public-repository semantics дала отличающийся `Q` в 109 из 132 фикстур;
- max TVD между literal-repository и paper-faithful `Q` составил `0.114661`;
- диагностический witness: при target `0.16` paper-rule выбирает вероятность `0.18`, а literal `near()` — `0.11`.

Доля `109/132` не является оценкой частоты расхождения на реальных Llama-шагах. Набор синтетических фикстур специально разнообразен и используется только для проверки семантики группировки.

## Прямой запуск авторского `near()`

Pinned файл `adg-stega.py` запускался без модификаций на пяти диагностических случаях. Получено:

- author vs literal-repository mismatches: 0;
- author vs paper mismatches: 1;
- little-endian bit conversion failures: 0;
- author checkout unchanged: True;
- статус `PASS`.

Следовательно, обнаруженное расхождение с Algorithm 1 действительно присутствует в опубликованном авторском файле, а не возникло в нашей транскрипции. В normalized benchmark приоритет отдан формальному правилу публикации; literal-поведение репозитория сохраняется как отдельный объект conformance-анализа.

## Publication-characteristic probe

Для характерной публикационной проверки выполнен один фиксированный запуск на 100 carrier tokens. Это Stage-4 probe, а не основной статистический эксперимент.

Условия:

- Llama-3.2-3B, зафиксированная revision;
- 100 carrier tokens;
- `repeats = 1`;
- `secret_id = stage4-adg-characteristic`;
- `method.random_seed = 42`;
- общий `top-k = None`, `top-p = 1.0`.

Результат:

| Показатель | Значение |
|---|---:|
| BPT | 4.6300 |
| Mean `D_KL(P_ref || Q)` | 0.009936 бит/токен |
| Mean `D_KL(Q || P_ref)` | 0.010232 бит/токен |
| Mean TVD | 0.028920 |
| Token round-trip | точный |
| Secret round-trip | точный |
| Ненулевое forward distortion | да |

Характерное поведение Table 1 воспроизведено качественно: ADG одновременно передает несколько бит на токен и сохраняет распределительное искажение небольшим, но ненулевым. Полученный BPT `4.63` ниже значений ER `5.147–5.650` из Table 1, а forward KL `0.009936` ниже опубликованного диапазона KLD1 `0.027–0.048`; эти различия не интерпретируются как улучшение или ухудшение метода из-за несопоставимых LM, токенизации, корпусов и контекстов.

Один 100-токенный запуск не используется для утверждений о среднем качестве ADG или его оптимальной рабочей точке. Массовые свипы и устойчивость выводов относятся к следующим этапам roadmap.

## Производительность и измерительный контур

Полный independent explicit-`Q` требует обхода всех ветвей группировки и является дорогой исследовательской операцией. Эта стоимость относится к `metric instrumentation` и исключена из показателей скорости самого ADG. Алгоритмическое время включает только группировку по фактически выбранному пути, terminal sampling и соответствующую работу decoder.

## Ограничения

1. Числа Table 1 напрямую не воспроизводятся из-за отличий модели, токенизации и данных.
2. Публичный author repository содержит семантическое расхождение с Algorithm 1; неизвестно, какая внутренняя версия кода использовалась авторами для получения Table 1.
3. Publication-characteristic probe выполнен одной 100-токенной траекторией и служит проверкой характерного поведения, а не статистической оценкой.
4. Более широкая проверка по prompts, секретам, рабочим точкам и резервной модели относится к последующим этапам.

## Вывод

ADG успешно прошёл Stage-4 интеграционную и воспроизводимостную проверку. Normalized-реализация совпала с независимой реализацией Algorithm 1 до машинной точности, полный secret round-trip на Llama-3.2-3B завершился без ошибок, а независимое explicit-`Q` подтвердило ожидаемое малое, но ненулевое искажение распределения.

Публичный авторский `near()` воспроизводимо расходится с правилом статьи на диагностическом случае; это расхождение зафиксировано отдельно и не скрывается внутри normalized adapter. Publication-characteristic probe дал `4.63` бит/токен при mean `D_KL(P_ref || Q) = 0.009936`, что подтверждает характерное сочетание высокой емкости и малого ненулевого KL без заявления о прямом численном воспроизведении Table 1.
