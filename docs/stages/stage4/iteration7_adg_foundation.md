# Этап 4 — итерация 7: foundation ADG

Зафиксирована нормализованная семантика ADG до реального Llama-запуска.

Реализовано:

- normalized encoder по Algorithm 1 статьи;
- собственный inverse decoder, отсутствующий в публичном репозитории;
- little-endian семантика индекса группы из авторских `bits2int`/`int2bits`;
- воспроизводимое терминальное сэмплирование через `MethodRandomSource`;
- независимое полное построение `Q_stego` по всему дереву групп;
- регистрация `adg` в unified runner;
- пример normalized-конфига и real-LM smoke script;
- unit/integration tests;
- ADR-0024 и первичный протокол воспроизводимости.

Критическое расхождение источников зафиксировано явно: Algorithm 1 требует токен с ближайшей вероятностью к `epsilon`, а публичный `near()` использует индекс `up` в одном из слагаемых. Normalized mode следует публикации. Следующая итерация должна не «подгонять» код к репозиторию, а отдельно охарактеризовать это расхождение на fixtures и затем выполнить publication-characteristic probe.
