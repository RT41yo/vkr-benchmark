# Проверка единственного неточного RRC-запуска после перехода на Decimal-границы

## Зачем нужна проверка

Проверка новой реализации RRC с накоплением границ в `Decimal` дала следующие результаты:

- 8 из 8 запусков завершились без ошибки процесса;
- `forward KL` конечна во всех 8 запусках;
- максимальная `forward KL` составляет примерно `1.38e-16` бит;
- максимальная TVD составляет примерно `1.03e-16`;
- 7 из 8 секретов восстановлены точно;
- один запуск `9967d088525fcf46` (`s5p0004:r02`) имеет `BER = 0.4150390625`.

Численная проблема с потерей малых положительных интервалов тем самым устранена. Однако один неточный полный цикл не позволяет пока закрыть проверку RRC.

## Что проверяется

Скрипт `scripts/diagnose_stage5_rrc_decimal_roundtrip.py` работает только с запуском `9967d088525fcf46`.

Сначала без загрузки модели он сравнивает сохранённые:

- `sender_token_ids` — токены, созданные RRC на стороне отправителя;
- `receiver_token_ids` — токены после преобразования в текст и повторной токенизации.

Затем декодер RRC запускается непосредственно на сохранённых `sender_token_ids`. Этот путь исключает преобразование

`token IDs -> text -> token IDs`.

Если исходный полный цикл неточен, токены отправителя и получателя отличаются, а прямое декодирование `sender_token_ids` восстанавливает все 1024 бита точно, единственный сбой относится к текстовому каналу, а не к построению Decimal-границ RRC.

## Команды

Быстрая проверка без модели:

```bash
python scripts/diagnose_stage5_rrc_decimal_roundtrip.py --inventory-only
```

Полная проверка одного запуска:

```bash
python scripts/diagnose_stage5_rrc_decimal_roundtrip.py
```

Результат сохраняется в:

```text
results/stage5/rrc_decimal_boundary_validation/roundtrip_attribution.json
```

## Критерий

Для отнесения сбоя к текстовому каналу одновременно должны выполняться условия:

1. исходный запуск имеет `roundtrip_exact=false`;
2. `sender_token_ids` и `receiver_token_ids` различаются;
3. прямое декодирование сохранённых `sender_token_ids` даёт точное восстановление 1024 бит и `BER=0`.

Production-код RRC эта диагностика не изменяет.
