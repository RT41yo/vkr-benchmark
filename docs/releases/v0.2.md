# Бенчмарк ВКР v0.2: базовая экспериментальная инфраструктура

Версия `v0.2` фиксирует результат Этапа 2 — рабочую базовую экспериментальную инфраструктуру для генеративной лингвистической стеганографии.

Это ещё не окончательный протокол основных экспериментов. Спецификация бенчмарка v0.1 остаётся зафиксированной, а окончательная версия экспериментального протокола v1.0 будет сформирована после пилотных прогонов и выбора диапазонов параметров согласно ROADMAP.

## Что входит в v0.2

- работающие реализации Bins, Huffman и Arithmetic Coding в единой инфраструктуре;
- общий адаптер языковой модели для Llama и Qwen;
- единое построение канонического `P_reference`;
- единый формат промптов, секретных последовательностей, параметров и условия остановки генерации;
- проверка полного цикла через обычный текстовый канал;
- расчёт ёмкости, эффективности использования энтропии, KL/TVD, NLL/PPL, BER и вычислительной эффективности;
- канонический `run_id` и отдельные артефакты каждого запуска;
- общая таблица `summary.parquet`;
- автоматическое формирование Markdown-сводки результатов;
- документ с точными определениями базовых метрик;
- ADR с ключевыми архитектурными решениями;
- автоматическая проверка готовности Этапа 2;
- презентация результатов Этапа 2 в формате Typst.

## Что не входит в v0.2

- подтверждение сходимости Bins, Huffman и Arithmetic Coding к авторским результатам — Этап 3;
- современные методы ADG, Discop, RRC и другие дополнительные методы — Этап 4;
- окончательные диапазоны параметров и набор рабочих точек методов — Этап 5;
- окончательный набор промптов, секретов и повторов — Этап 5;
- спецификация бенчмарка v1.0 — Этап 5;
- основные сравнительные эксперименты и Парето-анализ — последующие этапы ROADMAP.

## Проверка версии

Основные команды:

```bash
source .venv/bin/activate
pytest -q
python scripts/check_stage2_readiness.py
python scripts/summarize_results.py results/summary.parquet
```

Полная итоговая проверка:

```bash
python scripts/check_stage2_readiness.py --run-tests \
  --json-output results/stage2_readiness.json
```

Критерий технической готовности:

`Stage 2 technical readiness: READY`.

После включения итоговой презентации `docs/stages/stage2/stage_2.typ` состояние репозитория соответствует полному набору результатов Этапа 2 и может быть зафиксировано Git-тегом `v0.2`.
