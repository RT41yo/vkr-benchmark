# VKR Benchmark v0.2 technical milestone

`v0.2` — Stage-2 milestone базовой экспериментальной инфраструктуры. Это не финальная спецификация основных экспериментов; benchmark specification v0.1 остается frozen, а окончательный experimental protocol планируется зафиксировать как v1.0 после pilot sweeps.

## Scope v0.2

В milestone входят:

- normalized adapters Bins, Huffman и Arithmetic Coding;
- общий Llama/Qwen LM adapter layer и canonical `P_reference`;
- единые prompt/secret/config/termination inputs;
- ordinary-text encode/decode reliability path;
- capacity, entropy utilization, KL/TVD, raw-LM NLL/PPL, BER и computational-efficiency metrics;
- canonical `run_id` и per-run artifacts;
- `summary.parquet` и deterministic Markdown reporting;
- implementation-facing metric documentation и ADR trail;
- automated Stage-2 readiness audit.

## Не входит в v0.2

- author-result convergence claims для Bins/Huffman/Arithmetic Coding — Этап 3;
- ADG/Discop/RRC/дополнительные современные методы — Этап 4;
- финальные parameter ranges и operating points — Этап 5;
- окончательный corpus/repeat budget и benchmark specification v1.0 — Этап 5;
- основные сравнительные результаты и Pareto analysis — Этапы 6–8.

## Acceptance commands

```bash
source .venv/bin/activate
pytest -q
python scripts/check_stage2_readiness.py
python scripts/summarize_results.py results/summary.parquet
```

Для единого readiness-gate с повторным полным test suite:

```bash
python scripts/check_stage2_readiness.py --run-tests \
  --json-output results/stage2_readiness.json
```

При `Stage 2 technical readiness: READY` программный milestone v0.2 считается валидированным. Git tag/release целесообразно создавать после добавления обязательной по ROADMAP презентации Этапа 2.
