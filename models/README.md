# Local model weights

Эта директория предназначена для локальных копий моделей и исключена из Git.
Для текущего стенда ожидаются, в частности:

```text
models/
├── llama-3.2-3b/
└── qwen3-4b-base/
```

Файлы весов не входят в репозиторий бенчмарка. Конфигурация запуска должна
сохранять одновременно логический Hugging Face model id/revision для
происхождения эксперимента и локальный путь, из которого модель фактически
загружается на машине исследователя.
